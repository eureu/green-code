# Green Code Initiative. Решение кейса "Красная книга Москвы" от команды СДЕЛАНО В МИСИС

## Описание

**Красная книга Москвы** — это проект, который решает проблему осутствия цельного источника с актуальной информацией о краснокнижных видах животных Москвы. 

## Функциональность

- **Админ панель**: Для верификации присланных данных и удобного экспорта. Функция верификации
- **Рекомендации**: Современный интуитивный дизайн. Позволяет удержать новых пользователей. Простой пользовательский путь. Подталкивает пользователя к целевому действию
- **Возможности**: Развитие сообщества, волонтёрского движения вокруг Красной книги Москвы
- **Автоматическое распознавание вида**

## Установка

1. **Клонируйте репозиторий**:

   ```bash
   git clone https://github.com/eureu/green-code.git
   cd green-code
   
2. Установите зависимости:

  ```bash
  cd app/
  pip install -r requirements.txt
  cd ../green-code
  npm i
```
3. Запуск:

   ```bash
   npm run dev
   cd ../app
   uvicorn main:app --host=0.0.0.0 --port=8000 --reload

## Технологии и стек

- **Frontend**: TS, React, scss, vite
- **Backend**: python, FastAPI, Postgresql
